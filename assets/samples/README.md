# Bundled sample photographs

These images are copied unmodified from the scikit-image v0.25.2 sample dataset:
https://github.com/scikit-image/scikit-image/tree/v0.25.2/skimage/data

Credits and license information are documented in the upstream data loader:
https://github.com/scikit-image/scikit-image/blob/v0.25.2/skimage/data/_fetchers.py

The interface creates small demonstration inputs locally: 4x downsampling for
super-resolution, Gaussian noise with sigma 15 for denoising, and JPEG quality 10
for deblocking. Gallery thumbnails show the clean source, not restored output.
The test chart is generated by this project. No dataset package or runtime
network download is required.
